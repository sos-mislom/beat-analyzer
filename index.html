WAV to Unity beat maps

Generate rhythm timing JSON for Unity shooters, prototypes, and music games.

Analyze drum transients, estimate tempo, choose a playable beat grid, or export raw onset moments for more chaotic tracks.

Run the analyzer View repository
grid mode onsets mode Unity JSON
2 modes regular beat grid or strongest raw onsets
WAV input single files or whole folders
Unity ready load as TextAsset from Resources

Install

Small Python setup

git clone https://github.com/sos-mislom/beat-analyzer.git
cd beat-analyzer
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Usage

Choose the timing style

Use grid when the song has a clear pulse. Use onsets when the track is dense, broken, vocal-heavy, or has irregular hits that should drive gameplay moments.

Regular grid 
python beat_analyzer.py song.wav --mode grid --suffix _auto
Raw onsets 
python beat_analyzer.py song.wav --mode onsets --target-density 2.0 --suffix _onsets
Folder batch 
python beat_analyzer.py Music --mode onsets --suffix _onsets --overwrite

Output

Simple JSON for Unity

Drop the generated file into Assets/Resources/Music/<Track>/, load it as a TextAsset, and deserialize tempo, beats, and duration. 

{
  "tempo": 120.0,
  "beats": [0.12, 0.62, 1.12, 1.62],
  "duration": 2.0,
  "analysisMode": "grid",
  "analysis": {
    "interval": 0.5,
    "offset": 0.12,
    "onsetCount": 4
  }
}
